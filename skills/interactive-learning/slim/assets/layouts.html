Five ways to lay out a widget

Pick the arrangement that matches how the figures are read: one main figure, several linked ones, a wide trace, a figure with its own buttons, or a figure beside the text that explains it.

Dummy plots: \(\sin\), \(\cos\) and Gaussians. All layouts fall back to one column on narrow screens.

1. Hero figure with a controls column (aside)

Use it when one figure carries the idea and a handful of sliders drive it: the figure gets most of the width, the controls stay in view beside it.

const W = LX.widget(mount, { layout: "aside", title: "…", badge: "exact" });
const P = LX.plot(LX.fig(W, "caption"), { xlim, ylim, xlabel, ylabel });
const ctl = LX.controls(W);            // second child = the column
LX.slider(ctl, { label: "…", min, max, value, onInput: draw });
LX.guide(W, [["Figure", "…"], ["Slider", "…"]]);

2. Three linked figures, controls in the fourth cell (grid2)

Use it for three views of one state (for example a function, its transform and a derived quantity), so that no quadrant is left empty.

const W = LX.widget(mount, { layout: "grid2" });
const A = LX.plot(LX.fig(W, "…"), o), B = LX.plot(LX.fig(W, "…"), o);
const C = LX.plot(LX.fig(W, "…"), o);
const ctl = LX.controls(W);            // fourth cell: stacks vertically
LX.slider(ctl, { … }); LX.readout(ctl, "…");

3. Wide figure with a controls strip below (stack)

Use it for time traces, spectra and other figures that need width more than height; the controls sit in one row underneath.

const W = LX.widget(mount, { layout: "stack" });
const P = LX.plot(LX.fig(W, "…"), { width: 900, height: 280, … });
const ctl = LX.controls(W);            // a wrapping row
LX.slider(ctl, { … }); LX.slider(ctl, { … });
LX.legend(W, [["sum", "--accent", "line"], ["parts", "--muted", "dash"]]);

4. Floating buttons on the figure, controls on the left (aside + left)

Use it when an action belongs to the figure itself (keep a copy, reset, best fit): the buttons sit in its top-right corner where the eye already is.

const W = LX.widget(mount, { layout: "aside", left: true });
const ctl = LX.controls(W);            // first child = left column
const fig = LX.fig(W), P = LX.plot(fig, { … });   // caption below
LX.h("figcaption", { text: "…" }, fig);
const flt = LX.h("div", { class: "lx-float" }, fig);
LX.button(flt, "Keep a copy", keep, { cls: "lx-primary" });

5. Text beside the figure (split)

Use it inside a chapter when a short paragraph and the figure it describes should be read together.

const W = LX.widget(mount, { layout: "split" });
const txt = LX.h("div", { class: "lx-prose", html: "<p>…</p>" }, W);
LX.typeset(txt);
const col = LX.h("div", { class: "lx-col" }, W);   // figure + slider in one cell
const P = LX.plot(LX.fig(col, "…"), { … }); LX.slider(LX.controls(col), { … });
Source: none needed; the plots are elementary functions used as placeholders.
