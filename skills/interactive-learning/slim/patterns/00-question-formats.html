Five ways to ask a question about one widget

A particle in a box, and the five question formats a chapter can use around it. Each section says when the format is the right tool, then shows it working.

Infinite square well of width \(L\); in the widget \(\hbar = m = 1\) and energies in units of \(E_1(L{=}1) = \pi^2/2\)

A particle confined between two hard walls can only have standing waves that fit the box: \(\psi_n(x) = \sqrt{2/L}\,\sin(n\pi x/L)\), with \(n\) half wavelengths across the width \(L\). The widget shows these states and their energies.

Choice: confront a misconception

Use a multiple-choice question when there is a specific wrong belief to bring into the open. Each wrong option should be something a reasonable learner thinks, so the feedback can address it. Here the belief is that a higher quantum number always means a higher energy.

Number: estimate a scale

Use a numerical estimate when the point is the size of something: does the effect matter at this scale? The tolerance should be generous; an estimate within a factor of a few is often the real goal. The widget works in natural units, so this one asks for a real number in electronvolts.

Set: put the widget into the predicted state

Use a set question when the learner can express the prediction by operating the widget. It turns the widget into the answer box, and the check reads the widget state, so any correct configuration counts.

Sketch: predict a whole shape

Use a sketch when the shape of a dependence is the insight: a power law, a maximum, a divergence. Drawing forces a commitment over the whole range, which a single number does not. The matching curve in the widget stays hidden until the sketch is compared.

Explain: articulate the mechanism

Use an explanation at the end of a section, when the learner has seen the effect and should now say why it happens. There is no automatic grading: the model answer is for self-comparison.

Source: model knowledge. Standard treatment: Griffiths & Schroeter, Introduction to Quantum Mechanics, sec. 2.2 (the infinite square well).
